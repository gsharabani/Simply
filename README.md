# Show my parent · prototype

Design prototype for the Simply home assignment.

Maya finishes a song on her tablet and taps **Show my parent**. Her parent gets the recording on their phone, listens, and sends back a reaction with an optional note. The next time Maya plays, she sees it.

**View it:** https://gsharabani.github.io/Simply/

The whole prototype is a single file, `index.html`. Open it in any browser.
